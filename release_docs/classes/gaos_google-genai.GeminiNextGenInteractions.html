    Connects a WebRTC session to an existing live interaction.

    Experimental: Live Interactions SDK support is experimental and may change in future versions.

    receive() yields server events continuously over the "events" data channel until a terminal server event (interaction.completed, interaction.canceled, or reconnection_required) arrives or the connection detaches.

    Terminal server events, errors, and await connection.cancel() automatically flush and close the local WebRTC transport. Call connection.detach() to disconnect locally while leaving the server interaction resumable, or call await connection.complete() and consume connection.receive() until interaction.completed to finish.
